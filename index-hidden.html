View R script: Import the research dataset

Step-by-step: Create R/ 1. Open your main repository Go to phansok/phansok-learn.github.io. 2. Click Add file On the repository's main page, click Add file near the top right of the file list. 3. Select Create new file GitHub does not create an empty folder directly. You create a folder by creating a file inside it. 4. Enter the filename In the filename field at the top, type: R/01_import_data.R The R/ part creates the folder, and 01_import_data.R is the file inside it. 5. Add the script If you already have the contents of 01_import_data.R, paste them into the editor. If you do not have the script ready, you can create a temporary placeholder, such as: # R scripts for Phan Sok Learn # Add analysis scripts here.
